# Benchmarks

Entity linking and NER benchmarks with Wikidata entity resolution for evaluating the classification system.

## Datasets

| Benchmark | Entities | Resolved | Source |
|-----------|:--------:|:--------:|--------|
| [CleanCoNLL](cleanconll/) | 5,941 | 5,937 (99.93%) | Rucker & Akbik, EMNLP 2023 |
| [AIDA-YAGO](aida_yago/) | 5,598 | 5,595 (99.95%) | Hoffart et al., EMNLP 2011 |
| [BLINK](blink/) | 12,323 | controlled subset | Wu et al., EMNLP 2020 |

CleanCoNLL and AIDA-YAGO build on the CoNLL-2003 Reuters corpus. The BLINK package is a controlled entity disambiguation benchmark comparing YAGO-4.5 candidate types against OntoKG module-based candidate types.

### CleanCoNLL

Corrected CoNLL-03 with improved NER labels and Wikipedia entity linking annotations. 4 unresolved entities (deleted Wikipedia articles).

### AIDA-YAGO

Original AIDA CoNLL-YAGO entity linking benchmark merged with CoNLL-2003 NER types. 3 unresolved entities (deleted Wikipedia articles).

### BLINK

Controlled subset for the paper's entity disambiguation comparison. Includes candidate files, precomputed Voyage rerank results, preserved batch artifacts for both sides, and local Python scripts to reproduce the reported table without calling Voyage again.

For this experiment, the official YAGO 4.5 evaluation repo is `https://github.com/tigerchen52/eval_yago_el`.

## Entity Resolution

CleanCoNLL and AIDA-YAGO use the shared resolution pipeline in [`resolve_common.py`](resolve_common.py):

1. **Local parquet lookup** — joins against `data_dump_core_output/classified_with_sitelinks.parquet` (6.1M entities with enwiki sitelinks). Covers ~88–96% of titles. Extracts P31/P279 QIDs and labels directly from the classified claims JSON.
   This file is a prebuilt artifact from the HuggingFace dataset release, not a file generated by the default local 13-column classifier in this repo.
2. **URL decode fallback** — handles percent-encoded titles (e.g., `%27` → `'`).
3. **Wikipedia redirect resolution** — resolves redirected article titles via the Wikipedia API.
4. **Wikidata API fallback** — fetches QIDs, labels, descriptions, P31/P279 for remaining titles.
5. **Type label resolution** — fetches English labels for P31/P279 target QIDs not already extracted from claims.

### Cross-Dataset Validation

| Metric | Value |
|--------|-------|
| Shared entities (by QID) | 5,429 |
| Total unresolved | 7 (all deleted Wikipedia articles) |

The 7 unresolved titles are disjoint — none appear in the other dataset. CleanCoNLL's re-annotation fixed AIDA's 3 problematic links: `U._Chandana` → `Upul_Chandana` (full name), `International_cricketers_of_South_African_origin` → `South_Africa` (country), `Camelot,_Chesapeake,_Virginia` → dropped.

## Evaluation

Run all evaluations and regenerate reports:

```bash
uv run --project src/python python benchmarks/aida_yago/eval_classification.py --report
uv run --project src/python python benchmarks/cleanconll/eval_classification.py --report
uv run --project src/python python benchmarks/compare_datasets.py --report
```

Reports are auto-generated — re-run after YAML gate changes to update.

## Output Format

Both `cleanconll_entities.tsv` and `aida_entities.tsv` share the same schema:

| Column | Description |
|--------|-------------|
| wikipedia_title | Wikipedia page title (underscore-separated) |
| qid | Wikidata entity ID |
| label | English label from Wikidata |
| description | English description |
| p31_qids | P31 (instance-of) QIDs, semicolon-separated |
| p31_labels | P31 labels, semicolon-separated |
| p279_qids | P279 (subclass-of) QIDs, semicolon-separated |
| p279_labels | P279 labels, semicolon-separated |
